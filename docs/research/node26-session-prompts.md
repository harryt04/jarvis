# Copy-paste T3 prompts: Node 26 portfolio migration

Prepared 2026-11-10. These prompts implement the [migration plan](node26-migration-plan.md); they do not launch sessions. The plan and prompts are currently delivered together in Jarvis PR #18, so the worker blocks are self-contained and do not require that PR to have merged.

Start each session in the **Jarvis project**, using **GPT-6.1 Sol, medium reasoning** (Harry's default). Paste one entire fenced block per session. Choose a machine with the intended target checkout. Run at most three sessions at a time and at most two heavy builds per machine; start the next batch as slots free. Do not launch all blocks at once. No automatic launcher or new skill is installed by this document.

Order: HairnThere/RepoStaff verification; Wiki/Flowers/scaffold pilots; remaining conventional and stateful applications; Blockparty/Route Roulette. Rise Above Drone and PantryIQ include explicit baseline prerequisites. Utility scripts is an isolated smoke-check session.

Why Markdown: each fenced block is a complete plain-text task that survives copy/paste into a fresh T3 session, without inherited chat history or links to machine-only memory. The common title, label and results heading make outcomes searchable across repositories, like Lighthouse audits. Copy the **contents** of the fence. Each worker refreshes Jarvis origin/main and fetches the target's actual default branch, which may be master; it must not assume every target uses main.

Delivery convention: commit and PR title `chore(node26): <session-start-date> migration and compatibility checks`, label `node26-migration`, body section `## Node 26 compatibility results`. Pin the date once per session and reuse its branch on resumption. Search for existing open work first. These are review PRs; Lighthouse's scoped auto-merge permission does not transfer. Verification-only sessions open no empty PR and report their evidence in the final response. Results belong in target PRs, not in a shared Jarvis run log; do not alter Lighthouse runs.json.
