Look and color

Vercel's structure (Geist type, tight spacing, hairline borders, generous white space) with color doing real work instead of grayscale. Three candidate themes; all pair a cool primary with a warm accent, the pairing that stays distinct under red-green color blindness. Pick one in the Decisions section.

No red-versus-green anywhere. Unavailable days are struck through as well as dimmed.

  • T-1All colors come from the CSS variables in this file's <style> block; no raw hex in components.
  • T-2shadcn/ui primitives only (Button, Card, Tabs, Switch, Select, Calendar, Badge, Sidebar, Dialog, Form, Sonner). Tailwind v4, new-york style.
  • T-3Geist for UI, Geist Mono for times, durations, keys and code.
  • T-4Text contrast meets WCAG AA in light and dark for the chosen theme.
  • T-5Every state that uses color also has an icon, label, or text decoration.
  • T-6Visible focus ring (2px, --ring) on every interactive element.
