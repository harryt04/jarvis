## Representative procedure flows

1. **Customer research:** read existing product-marketing context; choose analysis of supplied assets, collection from communities, or both; extract jobs, pains, triggers, outcomes, language, and alternatives; cluster by frequency/intensity and segment; label confidence and sample limitations; agree the requested deliverable. The skill requires at least five independent points per segment before persona/messaging conclusions. Source selection dispatches to `references/source-guides.md`. This is a domain research recipe, separate from the short generic `research` skill, which requests a background agent and a cited Markdown report. ([Committed customer-research:12–120](https://github.com/harryt04/agent-skills/blob/45ebcde340a488412357592f4251cec1eb0f093c/customer-research/SKILL.md#L12-L120), [deliverables:231–256](https://github.com/harryt04/agent-skills/blob/45ebcde340a488412357592f4251cec1eb0f093c/customer-research/SKILL.md#L231-L256), [generic research:6–12](/Users/harry/.agents/skills/research/SKILL.md:6)).

2. **Engineering work:** setup explores the repository, establishes tracker/domain conventions, presents drafts, and writes `docs/agents/issue-tracker.md`, `domain.md`, optionally `triage-labels.md`, plus an existing agent-instructions file. `to-spec` synthesizes the conversation, agrees test seams, and publishes to the configured tracker. `implement` calls TDD where appropriate, typechecks/tests, runs review, and commits. Review pins a nonempty merge-base diff, locates standards/spec, dispatches two independent agents, and reports Standards and Spec separately; documented repository standards override its smell heuristics. These are substantive side effects and invocation-specific gates, not standing authorization. ([Setup:19–116](/Users/harry/.agents/skills/setup-matt-pocock-skills/SKILL.md:19), [to-spec:7–19](/Users/harry/.agents/skills/to-spec/SKILL.md:7), [implement:7–15](/Users/harry/.agents/skills/implement/SKILL.md:7), [review:17–78](/Users/harry/.agents/skills/code-review/SKILL.md:17)).

3. **Requested Dobby update:** the agent writes two or three accurate paragraphs; the helper reads a message file and optional repository metadata, loads webhook configuration in environment/local-env/machine-env order, validates a Discord destination, scans common secret shapes, builds a truncated JSON embed with `jq`, and posts using `curl`. `--dry-run` writes the payload, but still requires valid configuration and dependencies.
